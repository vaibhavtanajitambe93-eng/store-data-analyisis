# NovaMart Retail Sales Analysis Dashboard

## Overview

**NovaMart Retail Sales Analysis** is an Excel-based data analytics project that explores retail sales performance and customer purchasing behavior. Using Microsoft Excel, raw sales data was transformed into an interactive dashboard that helps visualize trends, customer demographics, product performance, and regional sales insights.

> **Note:** NovaMart is a fictional retail brand created for portfolio and educational purposes.

## Project Objective

The objective of this project is to analyze retail sales data and answer key business questions:

* Which months generate the highest sales?
* Who are the most valuable customer segments?
* Which product categories perform best?
* Which states contribute the most revenue?
* Which sales channels drive the highest orders?

## Tools & Skills Used

* **Microsoft Excel**
* Pivot Tables & Pivot Charts
* Slicers (Interactive Filters)
* IF, SUMIFS, COUNTIFS Functions
* Data Cleaning & Formatting
* Dashboard Design

## Interactive Dashboard

The dashboard includes:

* **Total Sales Revenue**
* **Total Orders**
* **Monthly Sales Trend**
* **Sales by Product Category**
* **Age Group & Gender Analysis**
* **Top 5 States by Sales**
* **Sales Channel Performance**
* **Order Status Analysis**
* Interactive slicers for dynamic filtering

## Key Business Insights

* Identified peak sales months to understand seasonal demand.
* Analyzed purchasing behavior across different age groups.
* Compared sales performance between male and female customers.
* Evaluated the highest-performing product categories.
* Measured revenue contribution by state and sales channel.
* Tracked delivered, cancelled, and returned orders for operational analysis.

## Business Value

This dashboard enables retail managers to monitor sales performance, identify profitable customer segments, optimize marketing strategies, and make data-driven business decisions through an easy-to-use interactive Excel dashboard.
